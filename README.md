# rachide-skills

Skills grátis do Claude por João Victor Rachide (@rachide.ai) e RVM.

| Plugin | Skills |
|---|---|
| `medicina-gratis` | osce-trainer |
| `ia-que-vende` | raio-x-de-oferta, espiao-de-concorrente, diagnostico-de-automacao |

## Instalar no Claude Code
```
/plugin marketplace add rrrachide2010/rachide-skills
/plugin install medicina-gratis@rachide-skills
/plugin install ia-que-vende@rachide-skills
```

## Instalar no claude.ai
1. Configurações › Capacidades: ative "Execução de código e criação de arquivos".
2. Personalizar › Skills › "+" › Criar skill › Carregar uma skill.
3. Suba o zip de cada skill (baixe em jvrachide.vercel.app/skills).

Kits completos (Internato, Consultório, Fábrica de Criativos): jvrachide.vercel.app/skills
